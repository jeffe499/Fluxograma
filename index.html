Como funciona — Segunda tela (Área principal) Topo / Status Nome do usuário — mostra quem está logado. Status — indica o estado atual (pronto, logado, salvo local, restaurado, importado, etc.). Sino (🔔) — abre a última notificação (ou uma mensagem de teste). Toca som, anima o sino e abre o overlay. Formulário — adicionar tarefa Título (obrigatório) — nome curto da tarefa (ex.: Álgebra). Disciplina (select) — etiqueta/assunto da tarefa; usada para colorir e agrupar visualmente. Data — dia agendado (aaaa-mm-dd). Pode ficar vazio para tarefas sem data. Hora — horário (hh:mm). Se preenchido, o alarme pode disparar na hora marcada. Duração (min) — tempo estimado em minutos (opcional). Adicionar — cria a tarefa e salva localmente no navegador. Pesquisar e filtros Campo de pesquisa — filtra tarefas em tempo real por título ou descrição. Filtros (Todas / Próximas / Concluídas): Todas — mostra tudo. Próximas — tarefas pendentes e com data/hora no futuro (ou sem data). Concluídas — mostra somente tarefas marcadas como feitas. Legenda de disciplinas Mostra as disciplinas cadastradas com bolinhas coloridas para identificação rápida das tarefas. Lista de tarefas Clique no item — abre o overlay com título, data/hora e descrição completa. Marcar — alterna entre pendente / concluída. Tarefas concluídas ficam esmaecidas. Excluir — remove a tarefa (confirmação é solicitada). Ordenação — tarefas são listadas por data/hora/título para facilitar visualização. Overlay de notificação (tela cheia) Exibe título, data/hora e descrição completa. Fechar — volta à lista. Adiar (Snooze) — botões 5 / 10 / 30 min: movem a tarefa para agora + X minutos e reativam a notificação. O overlay também aparece automaticamente quando chega o horário de uma tarefa com data/hora. Importar / Exportar Exportar (.json) — baixa um arquivo .json com todos os dados do usuário (tarefas, disciplinas, configurações). Use para backup. Importar (.json) — selecione um arquivo .json previamente exportado. Ao importar, o sistema pergunta confirmação e substitui os dados atuais pelo conteúdo do arquivo. O import espera um JSON válido com a mesma estrutura; em caso de erro o processo é abortado e uma mensagem é exibida. Após import, os dados são salvos localmente e a interface é atualizada. Limpar concluídas Remove em lote todas as tarefas marcadas como concluídas. Sair Faz logout e volta para a tela de login. Sessão e dados permanecem salvos no navegador (localStorage). Comportamento de notificações Se o navegador permitir, o app pede permissão de notificações. Quando o horário de uma tarefa chega (janela de ±1 minuto), o alarme dispara: som, animação, confete e overlay. Se a tarefa não for notificada e ficar mais de 5 minutos passada, ela é marcada como notificada para evitar repetições contínuas. Acessibilidade e atalhos Escape fecha o overlay. O app atualiza aria-hidden/aria-live para melhorar experiência em leitores de tela. Elementos focam automaticamente ao mudar de tela (ex.: foco no campo Título após login) para acelerar o uso com teclado.
